# NodeSampler

This is a Max inspired node based interface designed for more flexible sampling in your daw. Load in any sounds you want, process them however you would like, and map them to a MIDI note.

## build instructions
- git clone --depth 1 --branch 8.0.10 https://github.com/juce-framework/JUCE.git juce
- run cmake -B build
- cd into SvelteUI
- run npm -i
- run npm run build
- cd back out
- run cmake --build build
- the built plugin can be found in /build/NodeSampler_artefacts
